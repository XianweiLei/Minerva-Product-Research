# Minerva Product Research

NVIDIA Minerva 产品与 UX 研究，基于 NVIDIA 官方公开产品资料、技术博客和 Minerva 1.0.1 文档整理。

## 内容

- 产品定位、目标用户与 AI Factory 运维场景
- 能力架构与完整调查工作流
- Dashboard、Topology、Anomalies、Incidents、Trends 与 Ask Sherlock 的逐屏解析
- 12 张内嵌官方图片及来源链接
- 自动化边界、版本限制、设计启发与常见问题

## 阅读

下载并用浏览器打开 `index.html`。图片已内嵌，可离线阅读，支持点击放大和打印。GitHub 文件页面显示源码，不直接渲染网页。

## 资料说明

资料核对日期：2026-10-27。研究以公开资料为依据，未登录真实客户环境。报告中区分了已确认功能、设计判断与建议方案。

Incidents 配图来自官方事件关联场景展示，并非独立 Incidents 列表页截图。公开截图可能来自不同文档示例与产品阶段，不构成同一运行环境的连续操作记录。

截图与原始产品资料版权归 NVIDIA 所有。`sources.json` 提供截图来源索引。产品事实及可用性以 NVIDIA 对应版本文档为准。
